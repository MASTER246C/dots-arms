# Third-party boundaries

The R4 review package contains authored CAD candidates and simplified component envelopes. Manufacturer names in documentation identify reference components, not endorsements or a sublicense to vendor intellectual property. No vendor source STEP/PDF/ZIP folders are included. Original CAD bytes and design notices are retained. The public archive adds licensing/source notes and removes one personal-use sentence from its README; its manifest was regenerated.

The later R17 partial-arm review contains retained vendor-source actuator solids. Its raw FCStd file is deliberately not distributed here because redistribution rights have not been established. This omission does not make R4 the latest or a qualified replacement.

No paid Unity shader kit, API key, activation token, private research or unrelated portfolio asset is included.
